# 🧠 Memory Forensics Reference

A collection of reference documents designed to support the study and practice of Windows Memory Forensics.

## 📚 Documents

### Volatility 3 Plugin Reference
A categorized quick-reference guide covering commonly used Volatility 3 plugins for memory analysis and forensic investigations.

### FTK Imager Guide
A practical reference covering forensic acquisition, memory capture, evidence handling, image analysis, and examination workflows.

## 🎯 Purpose

The documents in this repository were created as quick-reference materials to assist during Windows Memory Forensics investigations and learning activities.

If you are new to Memory Forensics, these guides can help you understand:

- Evidence acquisition
- Memory capture
- Image verification
- Investigation workflow
- Memory analysis tools
- Forensic best practices

Together, they provide a structured reference for understanding the process involved in conducting a memory forensic investigation.
